# K9 Drone — Android app for FLOW_WIFI / KY UFO

Приложение для управления дроном с Wi-Fi `FLOW_WIFI_xxxxx` (приложение KY UFO).

## Сборка APK через GitHub (без компьютера)

1. Зайди на [github.com](https://github.com) и войди / зарегистрируйся.
2. Нажми **New repository** → имя например `K9DroneApp` → **Create repository**.
3. На странице репозитория нажми **uploading an existing file**.
4. Перетащи **все файлы и папки** из архива `K9DroneApp` (включая `.github`) и нажми **Commit changes**.
5. Перейди во вкладку **Actions**.
6. Выбери workflow **Build APK** → **Run workflow** → **Run workflow**.
7. Подожди 3–5 минут, пока статус станет зелёным.
8. Открой завершённый workflow → внизу в разделе **Artifacts** скачай **K9Drone-debug**.
9. Распакуй zip → получишь файл `app-debug.apk`.
10. Установи APK на телефон (разреши установку из неизвестных источников).

## Как пользоваться

1. Включи дрон.
2. Подключи телефон к Wi-Fi `FLOW_WIFI_0d30d8` (или похожей).
3. Открой приложение → нажми **«Подключить»**.
4. Должно появиться видео и заработать стики.

### Управление

| Элемент       | Действие                              |
|---------------|---------------------------------------|
| Левый стик    | Газ + Yaw                             |
| Правый стик   | Pitch + Roll                          |
| Взлёт         | Автоматический взлёт                  |
| Посадка       | Посадка                               |
| STOP          | Аварийная остановка                   |
| Камера ↕      | Переключение передняя / нижняя        |
| ▲ UP / ▼ DN   | Проба команд наклона камеры           |

## Протокол

- Управление: UDP порт **7099**
- Видео: `rtsp://IP:7070/webcam`
- IP (пробуются): 192.168.1.1, 192.168.0.1, 192.168.4.1, 192.168.169.1

## Примечание про наклон

Кнопки ▲/▼ отправляют несколько вариантов скрытых команд. Если камера реально двигается — напиши, какая кнопка сработала.
